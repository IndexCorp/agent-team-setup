# Варианты стека по зонам (каталог для интервью)

Организатор предлагает 2–3 варианта с плюсами/минусами и рекомендацией.
Перед предложением сверяй актуальность версий по официальной документации —
этот список про характер выбора, а не про актуальные номера версий.
Если у владельца уже есть опыт/код в чём-то — это перевешивает.

## Бекенд (API)

| Вариант | Плюсы | Минусы |
|---|---|---|
| Python + FastAPI | Быстрая разработка, автодоки (OpenAPI), простая сверка доков с кодом | Производительность ниже Go/Node на CPU-bound |
| Node.js (NestJS/Fastify) | Один язык с фронтендом, TypeScript-контракты общие | Валидация/доки собираются вручную |
| Go (chi/echo) | Производительность, статическая типизация, деплой одним бинарём | Многословнее, slower итерации |

## Фронтенд (веб)

| Вариант | Плюсы | Минусы |
|---|---|---|
| React + Vite + TS | Экосистема, найм, много готовых UI-китов | Легко перегрузить зависимостями |
| Vue 3 + Vite + TS | Проще порог, реактивность из коробки | Экосистема меньше |
| Astro/статика + островки | Скорость витрины/лендинга, SEO | Не для сложных интерактивных приложений |

## Мобильный

| Вариант | Плюсы | Минусы |
|---|---|---|
| Flutter | Одна кодовая база iOS+Android, предсказуемый UI | Собственный рендер (не нативные контролы), объём бинаря |
| React Native (Expo) | JS-экосистема, OTA-обновления, нативные контролы | Мосты/нативные модули — источник граблей |
| Нативный Kotlin + Swift | Максимум платформы, лучший профиль производительности | Две кодовые базы = двойная работа |

## Админ-панель (если отдельная зона)

- React + Vite + TS + компонентный кит (TanStack Query/Router) — дефолт;
- сервер-рендер (Django admin / Refine) — если панель простая и CRUD-ная.

## QA (если отдельная зона)

- Ручное тестирование по чек-листам + прогон смоков зон (без автотестов);
- Playwright (web) — если владелец хочет автотесты E2E.

## Правила предложения

1. Никогда не предлагать стек, которого нет в официальной документации
   (проверено WebSearch/WebFetch).
2. Рекомендация — одна, с обоснованием под конкретный проект, а не «в целом».
3. Ответ «не решил» — валиден: зона стартует по правилу первой сессии.
