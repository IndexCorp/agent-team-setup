# Гейт «доки ↔ код»: алгоритм и пример адаптации

Назначение: сделать забывчивость невозможной. Изменил контракт (эндпоинт,
модель) — скрипт падает и перечисляет расхождения; зелёный скрипт =
доки синхронны. Ложится в гейт бекенд-зоны перед коммитом.

## Алгоритм (стек-независимый)

1. **Извлечь фактический контракт из кода** — не из ручных списков, а из
   источника истины фреймворка:
   - маршруты: из объекта приложения/роутера (FastAPI — `app.openapi()["paths"]`,
     Express — таблица маршрутов, Django — URLconf);
   - модели/схемы: из метаданных ORM (SQLAlchemy `metadata.tables`,
     Prisma schema, Django models) или схем валидации.
2. **Извлечь задокументированный контракт из доков** — парсером секций
   (заголовки таблиц/разделов). Держать формат доков машиночитаемым:
   одна сущность = один заголовок, поля/маршруты = строки таблицы.
3. **Нормализовать и сравнить в обе стороны**: код без доки И доки без кода —
   обе ошибки. Параметризованные пути сравнивать структурно (`{id}` ≡ `{user_id}`).
4. **Игнор-лист** служебных маршрутов (`/docs`, `/openapi.json`, healthcheck).
5. Вывод: при расхождении — список проблем по группам и **exit 1**;
   при синхронности — сводка «N эндпоинтов / M таблиц» и exit 0.
6. Вписать скрипт в гейт зоны в AGENTS.md: `compileall/lint → смок →
   check_docs_sync`.

## Практические грабли парсинга доков (из проекта-первоисточника)

- Экранированный пайп `\|` внутри ячейки таблицы — не разделитель:
  заменять перед сплитом.
- Путь в описании (`/a`/`/b`) ловится как маршрут: голый `/` считать
  маршрутом только если вся ячейка — путь.
- Query-часть (`/path?x=`) — не часть маршрута: отрезать до `?`.
- Имена параметров пути не важны: нормализовать `{...}` → `{}`.
- Псевдонимы колонок/полей в доках порождают ложные расхождения —
  в доках поле называется так, как в модели.

## Для других стеков

- **Django**: routes из `django.urls.get_resolver()`, модели из
  `django.apps.apps.get_models()` + `_meta.fields`; доки — те же таблицы.
- **NestJS/Fastify**: маршруты из декораторов/роутера, DTO из классов
  валидации; иначе — минимум: скрипт сверяет список префиксов эндпоинтов.
- **Без API/БД** (статика, CLI): гейт не нужен — вместо него чек-лист в
  README зоны («собрано/запущено перед коммитом»).

Скрипт — единственный исполняемый артефакт, который организатор пишет
сам; он живёт в зоне бекенда и правится её агентом как код проекта.
