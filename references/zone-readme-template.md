## Правила зоны

- **В коде не оставлять комментарии (критично)** — код самопонятен.
- **Контракты — только из доков проекта**; расхождение = письмо бекенду.
- Чужие зоны не трогать (гейт: `zones.yml` + pre-commit hook); задания
  соседям — через их ящики.
- Чистый код: без дубликатов (сначала поиск готового по зоне), линтер
  в гейте, ошибки на границах обрабатываются — см. «Чистый код» в AGENTS.md.

## Критерии готовности (DoD)

1. {{ZONE_GATE: сборка/линт/смок зоны зелёные}}.
2. Новая фича/фикс = новые проверки (негативные кейсы тоже).
3. {{SECURITY_GATE: security-ревью по диффу, где применимо}}.
4. Контракт менялся? Доки обновлены в том же коммите ({{DOCS_GATE}}).
5. Коммит затрагивает только файлы своей зоны (иначе — письмо соседу).

## Грабли (append-only)

Наступил — добавь строку: симптом → причина → как обойти/починить.
Строка, потерявшая смысл (починена, неактуальна), удаляется тем же
агентом, который починил причину. Это передача опыта между сессиями,
а не история изменений: правила и контракты — в доках, известные
ловушки — здесь.

- (пусто)
```
